IXe siècle · Bagdad

Al-Kindi & l'analyse fréquentielle

Cryptanalyse Statistique Niveau débutant

📖 1. Présentation

Auteur
Al-Kindi (801–873)
Lieu
Bagdad, califat abbasside
Type
Cryptanalyse statistique

Au IXe siècle, le savant arabe Abū Yūsuf Al-Kindi rédige Risāla fī Istikhrāj al-Mu'amma — le premier traité connu sur le cassage de chiffres. Sa contribution majeure : l'analyse fréquentielle, qui exploite le fait que dans toute langue, certaines lettres apparaissent plus souvent que d'autres (le 'E' en français, le 'E' en anglais, le 'A' en arabe…).

Ce simple constat statistique suffit à briser des siècles de chiffres par substitution — y compris le chiffre de César.

⚙️ 2. Principe

Dans un texte français standard, voici les fréquences attendues :

E
14.7%
A
7.6%
S
7.9%
I
7.5%
T
7.2%

Si on chiffre un texte avec César (k=3), la lettre la plus fréquente du chiffré sera très probablement 'H' (E + 3). On en déduit la clé sans même tester toutes les possibilités.

🧮 3. Mathématiques

On compare la distribution observée à la distribution attendue avec le chi-carré (χ²) :

χ² = Σ (Oi − Ei)² / Ei
  • Oi : fréquence observée de la lettre i dans le texte
  • Ei : fréquence attendue (référence française)
  • Plus χ² est petit, plus la distribution colle au français : on a trouvé la bonne clé

def chi_squared(text):
    text = [c for c in text.upper() if c.isalpha()]
    n = len(text)
    if n == 0: return float('inf')
    chi = 0
    for letter, exp_pct in FRENCH_FREQ.items():
        obs = text.count(letter)
        exp = exp_pct * n / 100
        if exp > 0:
            chi += (obs - exp) ** 2 / exp
    return chi

def break_caesar(cipher):
    best_k, best_chi, best_plain = 0, float('inf'), ''
    for k in range(26):
        plain = ''.join(
            chr((ord(c) - 65 - k) % 26 + 65) if c.isalpha() else c
            for c in cipher.upper()
        )
        c = chi_squared(plain)
        if c < best_chi:
            best_k, best_chi, best_plain = k, c, plain
    return best_k, best_plain

const FRENCH = {A:7.64,B:0.90,C:3.26,D:3.67,E:14.72,F:1.06,G:0.87,H:0.74,
  I:7.53,J:0.61,K:0.05,L:5.46,M:2.97,N:7.10,O:5.80,P:2.52,Q:1.36,
  R:6.69,S:7.95,T:7.24,U:6.31,V:1.84,W:0.04,X:0.43,Y:0.13,Z:0.13};

function chiSquared(text) {
  const letters = [...text.toUpperCase()].filter(c => /[A-Z]/.test(c));
  if (!letters.length) return Infinity;
  return Object.entries(FRENCH).reduce((sum, [l, pct]) => {
    const obs = letters.filter(c => c === l).length;
    const exp = pct * letters.length / 100;
    return exp > 0 ? sum + (obs - exp) ** 2 / exp : sum;
  }, 0);
}

function breakCaesar(cipher) {
  let best = {k: 0, chi: Infinity, plain: ''};
  for (let k = 0; k < 26; k++) {
    const plain = [...cipher.toUpperCase()].map(c => {
      const code = c.charCodeAt(0);
      return code >= 65 && code <= 90
        ? String.fromCharCode((code - 65 - k + 26) % 26 + 65)
        : c;
    }).join('');
    const chi = chiSquared(plain);
    if (chi < best.chi) best = {k, chi, plain};
  }
  return best;
}

🌍 6. Pourquoi c'est révolutionnaire

✓ Impact historique
  • Premier traité de cryptanalyse au monde
  • A inspiré les cryptanalystes pendant 1000 ans
  • Encore utilisé pour casser tous les chiffres simples
✗ Ce qu'elle ne casse pas
  • Chiffres polyalphabétiques (Vigenère)
  • Chiffrement par blocs modernes (AES)
  • Textes trop courts (statistiques peu fiables)

💥 Failles & attaques connues

Vulnérabilités spécifiques, attaques connues, cassures historiques.

Textes trop courts

Moins de ~200 caractères → statistiques peu fiables, la méthode échoue.

Mélange de langues

Texte en plusieurs langues brouille la distribution fréquentielle attendue.

Texte technique / code

Distribution non-standard (programmation, listes) → analyse fréquentielle peu fiable.

Chiffres polyalphabétiques

Vigenère neutralise l'analyse simple — il faut d'abord détecter la longueur de clé.
