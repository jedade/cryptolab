📖 1. Présentation

La cryptographie quantique ne cherche pas à résister aux ordinateurs quantiques — c'est le rôle de la cryptographie post-quantique. Elle utilise directement les lois de la physique quantique (no-cloning, perturbation par la mesure) pour garantir la sécurité, théoriquement de manière inconditionnelle.

QKD (Quantum Key Distribution): distributing a secure symmetric key between two parties via an optical channel."> Son application principale est la QKD (Quantum Key Distribution) : distribuer une clé symétrique sécurisée entre deux parties via un canal optique.

⚙️ 2. BB84 — pas à pas

  1. Alice génère n bits aléatoires et n bases aléatoires (+ rectilinéaire ou × diagonale).
  2. Elle encode chaque bit comme une polarisation de photon (4 états possibles).
  3. Bob mesure chaque photon avec une base également choisie au hasard.
  4. Alice et Bob comparent publiquement les bases (pas les bits) et ne gardent que les positions où elles coïncident.
  5. Si Eve a intercepté, mesuré et renvoyé, elle a forcé l'effondrement de la fonction d'onde dans ~25% des cas → un échantillon de bits comparés révèle sa présence.

🧮 3. Variante E91 (Ekert, 1991)

Au lieu de polariser des photons, on génère des paires intriquées partagées entre Alice et Bob. La sécurité repose sur la violation des inégalités de Bell : si Eve écoute, les corrélations quantiques sont cassées et détectables statistiquement.

Théorème de non-clonage (Wootters & Zurek, 1982) : ∄ opération unitaire qui copie un état quantique inconnu. C'est ce qui empêche Eve d'écouter passivement.

import random

def bb84(n, eve=False):
    a_bits  = [random.randint(0,1) for _ in range(n)]
    a_bases = [random.choice('+x') for _ in range(n)]
    b_bases = [random.choice('+x') for _ in range(n)]
    b_bits = []
    for i in range(n):
        bit, base = a_bits[i], a_bases[i]
        if eve:
            e_base = random.choice('+x')
            if e_base != base:
                bit = random.randint(0,1)  # perturbation
        if b_bases[i] == base:
            b_bits.append(bit)
        else:
            b_bits.append(random.randint(0,1))
    shared = [(a_bits[i], b_bits[i]) for i in range(n) if a_bases[i] == b_bases[i]]
    errors = sum(1 for a,b in shared if a != b)
    return shared, errors

shared, errs = bb84(100, eve=True)
print(f"Bits gardés : {len(shared)}, erreurs : {errs} → QBER {errs/len(shared)*100:.1f}%")
function bb84(n, eve=false) {
  const aBits  = Array.from({length:n}, ()=> Math.random() < 0.5 ? 0 : 1);
  const aBases = Array.from({length:n}, ()=> Math.random() < 0.5 ? '+' : 'x');
  const bBases = Array.from({length:n}, ()=> Math.random() < 0.5 ? '+' : 'x');
  const bBits = [];

  for (let i=0; i<n; i++) {
    let bit = aBits[i], base = aBases[i];
    if (eve) {
      const eBase = Math.random() < 0.5 ? '+' : 'x';
      if (eBase !== base) bit = Math.random() < 0.5 ? 0 : 1;
    }
    bBits.push(bBases[i] === base ? bit : (Math.random() < 0.5 ? 0 : 1));
  }

  const shared = [];
  for (let i=0; i<n; i++) if (aBases[i] === bBases[i]) shared.push([aBits[i], bBits[i]]);
  const errors = shared.filter(([a,b]) => a !== b).length;
  return { shared, errors, qber: errors / shared.length };
}

🌍 6. Cas réel & limites

✓ Déploiements
  • Satellite chinois Micius (2017) — QKD intercontinental
  • Réseaux QKD Genève, Tokyo, Vienne, Pékin
  • ID Quantique, Toshiba — produits commerciaux
  • Banques suisses, élections cantonales (Genève)
✗ Limites pratiques
  • Distance limitée (~few hundred km en fibre)
  • Nécessite matériel optique spécialisé
  • Attaques par implémentation (détecteurs aveuglés)
  • Ne remplace pas signatures / asymétrique
  • NSA & ANSSI : préfèrent la PQC à la QKD

💥 Failles & attaques connues

Vulnérabilités spécifiques, attaques connues, cassures historiques.

Détecteurs aveuglés (Makarov, 2010)

Eve injecte un laser puissant pour saturer les détecteurs de Bob → contrôle de ses mesures.

Trojan-horse attack

Eve illumine l'appareil d'Alice avec un laser et lit la réflexion pour deviner les bases.

Mauvaise post-traitement (correction d'erreur)

Si la correction d'erreur fuit trop d'information, le secret partagé est compromis.

Authentification du canal classique

QKD nécessite un canal classique authentifié — sinon MITM trivial.

Coût pratique

Limité à ~few hundred km en fibre, équipement très spécialisé. ANSSI préfère PQC.
