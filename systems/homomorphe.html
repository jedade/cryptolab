Chiffrement homomorphe

Calcul sur chiffré PHE · SHE · FHE Avancé

📖 1. Présentation

Le chiffrement homomorphe permet de réaliser des calculs directement sur des données chiffrées, sans jamais les déchiffrer. Le résultat, une fois déchiffré, est identique à celui qu'on aurait obtenu sur les données en clair.

C'est l'outil ultime du cloud computing confidentiel et du machine learning préservant la vie privée.

PHE
Partiel — UNE opération (+ ou ×)
RSA, ElGamal, Paillier
SHE
Quelques opérations (profondeur limitée)
BGV, BFV
FHE
Pleinement — toutes opérations
Gentry 2009 · CKKS · TFHE

⚙️ 2. Le cryptosystème de Paillier (1999)

Paillier est additivement homomorphe : multiplier deux chiffrés donne le chiffré de la somme des clairs.

E(m₁) · E(m₂) mod n²   =   E(m₁ + m₂)

🧮 3. Mathématiques de Paillier

Clés : choisir p, q premiers · n = p·q · λ = lcm(p−1, q−1)
g = n + 1 (générateur simple valable) · μ = λ⁻¹ mod n
E(m) = gm · rn mod n²   (r aléatoire)
D(c) = L(cλ mod n²) · μ mod n   avec L(x) = (x−1)/n

Sécurité = problème de résiduosité composite (lié à la factorisation de n). Notez la composante aléatoire r : Paillier est probabiliste (même message → chiffrés différents).

function modpow(b,e,m){let r=1n;b=((b%m)+m)%m;while(e>0n){if(e&1n)r=(r*b)%m;e>>=1n;b=(b*b)%m;}return r;}
function modinv(a,m){let [or,r]=[((a%m)+m)%m,m],[os,s]=[1n,0n];while(r){const q=or/r;[or,r]=[r,or-q*r];[os,s]=[s,os-q*s];}return ((os%m)+m)%m;}
const lcm = (a,b) => { const g=(x,y)=>{while(y){[x,y]=[y,x%y];}return x;}; return a*b/g(a,b); };

function paillierKeys(p, q) {
  const n = p*q, n2 = n*n;
  const lambda = lcm(p-1n, q-1n);
  const g = n + 1n;
  // L(u) = (u-1)/n ; mu = (L(g^λ mod n²))⁻¹ mod n
  const mu = modinv((modpow(g, lambda, n2) - 1n) / n, n);
  return { pub: {n, g, n2}, priv: {lambda, mu, n} };
}

function encrypt(pub, m, r) {
  return (modpow(pub.g, m, pub.n2) * modpow(r, pub.n, pub.n2)) % pub.n2;
}
function decrypt(priv, c) {
  const n2 = priv.n * priv.n;
  return ((modpow(c, priv.lambda, n2) - 1n) / priv.n * priv.mu) % priv.n;
}
// Homomorphisme additif
const sumCipher = (pub, c1, c2) => (c1 * c2) % pub.n2;

🌍 6. Cas réel & limites

✓ Cas d'usage
  • Vote électronique vérifiable (Helios)
  • Inférence ML sur données privées (CKKS)
  • Études médicales multi-centres
  • Cloud où le fournisseur ne voit pas les données
  • Apple Private Compute Cloud (2024+)
✗ Limites
  • FHE pur : 100× à 10000× plus lent que clair
  • Croissance du bruit → bootstrapping coûteux
  • Chiffrés volumineux (Mo voire Go par valeur)
  • Bibliothèques complexes (Microsoft SEAL, OpenFHE, Concrete)

💥 Failles & attaques connues

Vulnérabilités spécifiques, attaques connues, cassures historiques.

Croissance du bruit (SHE)

Au-delà d'une profondeur de multiplications, le bruit corrompt le déchiffrement.

Bootstrapping coûteux (FHE)

Réinitialisation du bruit : ~secondes par opération sur des données chiffrées.

Schémas spécifiques (RSA/Paillier multipliés)

Pas IND-CCA → manipuler en mode AEAD si possible.

Side-channel sur le décrypt

Timing/cache attaquent la clé privée de la même façon qu'en asymétrique classique.
