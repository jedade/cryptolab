ECDSA & EdDSA

Signature numérique Asymétrique Bitcoin · TLS · SSH

📖 1. Présentation

Inventeurs
Vanstone (ECDSA), Bernstein (EdDSA)
Années
1992 (ECDSA) · 2011 (EdDSA)
Type
Signature numérique elliptique

ECDSA (Elliptic Curve Digital Signature Algorithm) est l'adaptation de DSA aux courbes elliptiques — utilisé par Bitcoin (secp256k1), TLS, certificats. EdDSA (Edwards-curve Digital Signature Algorithm) est la version moderne : signatures déterministes 64 octets, plus sûre et plus rapide. Ed25519 est l'instance la plus connue, devenue standard pour SSH, Git, Tor, JWT.

⚙️ 2. Fonctionnement

ECDSA needs randomness k at each signature — a critical point:

1. Hash: e = HASH(message)
2. Pick random k ∈ [1, n−1]
3. Compute (x₁, y₁) = k·G  →  r = x₁ mod n
4. s = k⁻¹ · (e + r·d) mod n  (d = private key)
5. Signature = (r, s)

EdDSA eliminates randomness — k is derived deterministically from the message hash and part of the private key:

1. k = HASH(prefix ∥ message)  (prefix = secret derived from private key)
2. R = k·G
3. S = k + HASH(R ∥ A ∥ M) · a mod L  (a = private key)
4. Signature = (R, S), 64 bytes total
">

ECDSA nécessite un aléa k à chaque signature — un point critique :

1. Hash : e = HASH(message)
2. Choisir aléa k ∈ [1, n−1]
3. Calculer (x₁, y₁) = k·G  →  r = x₁ mod n
4. s = k⁻¹ · (e + r·d) mod n  (d = clé privée)
5. Signature = (r, s)

EdDSA élimine l'aléa — k est dérivé déterministiquement du hash du message et d'une partie de la clé privée :

1. k = HASH(prefix ∥ message)  (prefix = secret dérivé de la clé privée)
2. R = k·G
3. S = k + HASH(R ∥ A ∥ M) · a mod L  (a = clé privée)
4. Signature = (R, S), 64 octets total

🧮 3. Mathématiques

ECDSA: r = (k·G).x mod n,  s = k⁻¹ (e + r·d) mod n
EdDSA: k = H(prefix ∥ M) deterministic
Verification: u₁G + u₂A == R (ECDSA) / 8S·G == 8R + 8H·A (EdDSA)

💻 4. Code

from cryptography.hazmat.primitives.asymmetric.ec import generate_private_key, SECP256R1, ECDSA
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives import hashes

# === ECDSA (P-256) — encore très utilisé ===
ec_priv = generate_private_key(SECP256R1())
sig = ec_priv.sign(b"message", ECDSA(hashes.SHA256()))
ec_priv.public_key().verify(sig, b"message", ECDSA(hashes.SHA256()))

# === EdDSA (Ed25519) — choix moderne ===
ed_priv = Ed25519PrivateKey.generate()
sig = ed_priv.sign(b"message")           # 64 octets, déterministe
ed_priv.public_key().verify(sig, b"message")

# Bitcoin utilise ECDSA sur secp256k1. Migration progressive vers Schnorr (BIP340).
# Pour tout nouveau projet en 2026 : préférer Ed25519 partout où possible.
// Ed25519 via Web Crypto API (support 2023+)
const keyPair = await crypto.subtle.generateKey({ name: 'Ed25519' }, true, ['sign','verify']);
const message = new TextEncoder().encode('message');
const signature = await crypto.subtle.sign('Ed25519', keyPair.privateKey, message);
const ok = await crypto.subtle.verify('Ed25519', keyPair.publicKey, signature, message);
console.log(ok);  // true

// ECDSA P-256
const ecKp = await crypto.subtle.generateKey(
  { name:'ECDSA', namedCurve:'P-256' }, true, ['sign','verify']);
const ecSig = await crypto.subtle.sign(
  { name:'ECDSA', hash:'SHA-256' }, ecKp.privateKey, message);

🌍 5. Cas réel : avantages, inconvénients, failles

✅ Avantages
  • Signatures très petites (64 o pour Ed25519)
  • Très rapide (10-100× plus rapide que RSA)
  • EdDSA déterministe : pas besoin d'aléa fiable
  • Standard partout : Bitcoin, Ethereum, TLS, SSH, Tor, Git
⚠️ Inconvénients
  • ECDSA exige un RNG parfait — un k réutilisé = clé révélée
  • Validation des paramètres délicate (point pas sur courbe)
  • EdDSA support hardware encore limité (HSM, TPM legacy)
  • Aucun mécanisme de révocation intégré
💥 Failles connues
  • PlayStation 3 (2010) : k constant → master signing key extraite
  • Sony Bitcoin (2013) : RNG Android Java cassé → vol de BTC
  • Lattice attacks sur biais de k (Howgrave-Graham, 2001+)
  • Minerva (2019) : ECDSA leak via timing sur courbes lentes
  • Shor (quantique) : casse ECDSA et EdDSA → migration PQC
