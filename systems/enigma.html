1918 – 1945 · Allemagne

Machine Enigma

Rotors électromécaniques Symétrique Niveau intermédiaire

📖 1. Présentation

Inventeur
Arthur Scherbius (1918)
Cassée par
Rejewski, Turing, Welchman
Configurations
~158 quintillions

Enigma est la machine de chiffrement utilisée par l'Allemagne nazie pendant la Seconde Guerre mondiale. Brevetée en 1918, elle combine 3 (ou 4 sur l'Enigma M4 navale) rotors mobiles, un réflecteur et un tableau de connexions (plugboard). Sa cassure systématique par Bletchley Park, sous la direction d'Alan Turing, a raccourci la guerre de plusieurs années.

Premiers travaux mathématiques : Marian Rejewski (Pologne, 1932). Mise à l'échelle industrielle : Turing et sa Bombe électromécanique.

⚙️ 2. Fonctionnement

À chaque touche frappée, le courant traverse :

  1. Tableau de connexions (plugboard) — permute des paires de lettres
  2. Rotor I → Rotor II → Rotor III (chacun applique sa permutation)
  3. Réflecteur — renvoie le courant vers la sortie
  4. Rotor III → Rotor II → Rotor I (en sens inverse)
  5. Plugboard (à nouveau) → lampe correspondant à la lettre chiffrée
⚠️ Conséquence du réflecteur : une lettre ne peut jamais se chiffrer elle-même. Cette particularité a été exploitée à Bletchley Park.
💡 Auto-inverse : avec le même réglage, chiffrer KHOOR redonne HELLO. Inutile d'avoir un mode séparé pour déchiffrer.

🧮 3. Mathématiques

Le nombre total de configurations militaires (Enigma Wehrmacht) :

5 × 4 × 3 (ordre des rotors) × 26³ (positions) × 26³ (anneaux) × C(26,10)·9!! (plugboard)
≈ 1,58 × 10²⁰

Espace énorme — mais réduit drastiquement par les cribs (mots probables comme "Wettervorhersage", météo) et la propriété d'auto-inverse. La Bombe de Turing testait des positions en parallèle pour éliminer les contradictions.

🔍 4. Simulation Enigma simplifiée

3 rotors I, II, III (câblage historique) + réflecteur B. Sans plugboard pour simplifier. Les rotors avancent à chaque lettre.

Astuce : remets les mêmes positions et passe le résultat → tu retrouves le clair.

💻 5. Code (cœur de la simulation)

ROTORS = {
  'I':   "EKMFLGDQVZNTOWYHXUSPAIBRCJ",
  'II':  "AJDKSIRUXBLHWTMCQGZNPYFVOE",
  'III': "BDFHJLCPRTXVZNYEIWGAKMUSQO",
}
REFLECTOR_B = "YRUHQSLDPXNGOKMIEBFZCWVJAT"
A = ord('A')

def rotor_fwd(c, wiring, pos):
    return chr((ord(wiring[(ord(c) - A + pos) % 26]) - A - pos) % 26 + A)

def rotor_bwd(c, wiring, pos):
    idx = wiring.index(chr((ord(c) - A + pos) % 26 + A))
    return chr((idx - pos) % 26 + A)

def enigma(text, positions):
    p = [ord(x)-A for x in positions]
    out = []
    for ch in text.upper():
        if not ch.isalpha(): out.append(ch); continue
        # Stepping (simplifié : tous avancent ; vraie Enigma a un mécanisme avec encoches)
        p[2] = (p[2]+1) % 26
        x = ch
        for w, pos in zip(['III','II','I'], [p[2],p[1],p[0]]):
            x = rotor_fwd(x, ROTORS[w], pos)
        x = REFLECTOR_B[ord(x)-A]
        for w, pos in zip(['I','II','III'], [p[0],p[1],p[2]]):
            x = rotor_bwd(x, ROTORS[w], pos)
        out.append(x)
    return ''.join(out)

print(enigma("HELLO WORLD", "AAA"))
const ROTORS = {
  I:   "EKMFLGDQVZNTOWYHXUSPAIBRCJ",
  II:  "AJDKSIRUXBLHWTMCQGZNPYFVOE",
  III: "BDFHJLCPRTXVZNYEIWGAKMUSQO",
};
const REFLECTOR_B = "YRUHQSLDPXNGOKMIEBFZCWVJAT";
const A = 65;

const fwd = (c, wiring, pos) =>
  String.fromCharCode((wiring.charCodeAt((c.charCodeAt(0)-A+pos)%26) - A - pos + 52) % 26 + A);
const bwd = (c, wiring, pos) => {
  const i = wiring.indexOf(String.fromCharCode((c.charCodeAt(0)-A+pos)%26 + A));
  return String.fromCharCode((i - pos + 52) % 26 + A);
};

function enigma(text, positions) {
  const p = [...positions].map(x => x.charCodeAt(0) - A);
  return [...text.toUpperCase()].map(ch => {
    if (!/[A-Z]/.test(ch)) return ch;
    p[2] = (p[2] + 1) % 26;
    let x = ch;
    [['III',p[2]],['II',p[1]],['I',p[0]]].forEach(([w,pos]) => x = fwd(x, ROTORS[w], pos));
    x = REFLECTOR_B[x.charCodeAt(0) - A];
    [['I',p[0]],['II',p[1]],['III',p[2]]].forEach(([w,pos]) => x = bwd(x, ROTORS[w], pos));
    return x;
  }).join('');
}

🌍 6. Pourquoi elle est tombée

✓ Forces
  • ~10²⁰ configurations possibles
  • État interne change à chaque touche
  • Robuste face à la cryptanalyse manuelle de l'époque
✗ Failles exploitées
  • Une lettre n'est jamais chiffrée par elle-même
  • Cribs : messages stéréotypés (météo, "Heil Hitler")
  • Procédures opérationnelles répétitives
  • La Bombe de Turing testait des hypothèses en parallèle

💥 Failles & attaques connues

Vulnérabilités spécifiques, attaques connues, cassures historiques.

Auto-inversion du réflecteur

Une lettre ne se chiffre jamais en elle-même → réduit drastiquement l'espace des hypothèses.

Cribs (mots probables, Bletchley Park)

Messages stéréotypés (météo "Wettervorhersage", "Keine besonderen Ereignisse") = points d'entrée.

Bombe électromécanique de Turing (1940)

Tests massivement parallèles d'hypothèses, ~5h pour casser une clé du jour.

Procédures opérationnelles répétitives

Indicateurs de message répétés 2× ou clés de session devinables.

Capture de matériel (Cipher Bureau polonais, 1932)

Rejewski reconstitue le câblage des rotors à partir d'un manuel volé.
