1553 · Renaissance italienne

Chiffre de Vigenère

Polyalphabétique Symétrique Niveau intermédiaire

📖 1. Présentation

Inventeur réel
Giovan Battista Bellaso
Attribué à
Blaise de Vigenère (1586)
Surnom
"Le chiffre indéchiffrable"

Le chiffre de Vigenère est une généralisation du chiffre de César : au lieu d'un décalage fixe, on utilise un mot-clé qui fait varier le décalage à chaque lettre. Cette idée brillante neutralise l'analyse fréquentielle d'Al-Kindi — il a fallu 300 ans pour qu'il soit officiellement cassé (par Babbage et Kasiski au XIXe siècle).

⚙️ 2. Fonctionnement

On répète la clé au-dessus du message ; chaque lettre du message est décalée selon la lettre de clé correspondante (A=0, B=1, …, Z=25).

Clé répétée :
L E M O N L E M O N L E M O N
Message clair :
A T T A C K A T D A W N
↓
Message chiffré :
L X F O P V E F R N H R

🧮 3. Mathématiques

Ci = (Mi + Ki mod L) mod 26
Mi = (Ci − Ki mod L) mod 26
  • Mi : i-ème lettre du message (A=0…Z=25)
  • K : clé de longueur L, répétée cycliquement
  • Une même lettre claire peut être chiffrée différemment selon sa position → analyse fréquentielle simple échoue

💻 5. Code

def vigenere(text, key, decrypt=False):
    key = [ord(k) - 65 for k in key.upper() if k.isalpha()]
    if not key: return text
    out, j = [], 0
    for ch in text.upper():
        if 'A' <= ch <= 'Z':
            shift = -key[j % len(key)] if decrypt else key[j % len(key)]
            out.append(chr((ord(ch) - 65 + shift) % 26 + 65))
            j += 1
        else:
            out.append(ch)
    return ''.join(out)

print(vigenere("ATTACK AT DAWN", "LEMON"))           # LXFOPV EF RNHR
print(vigenere("LXFOPV EF RNHR", "LEMON", True))     # ATTACK AT DAWN
function vigenere(text, key, decrypt = false) {
  const k = [...key.toUpperCase()].filter(c => /[A-Z]/.test(c)).map(c => c.charCodeAt(0) - 65);
  if (!k.length) return text;
  let j = 0;
  return [...text.toUpperCase()].map(ch => {
    const code = ch.charCodeAt(0);
    if (code < 65 || code > 90) return ch;
    const shift = decrypt ? -k[j % k.length] : k[j % k.length];
    j++;
    return String.fromCharCode((code - 65 + shift + 26) % 26 + 65);
  }).join('');
}

console.log(vigenere("ATTACK AT DAWN", "LEMON"));         // LXFOPV EF RNHR
console.log(vigenere("LXFOPV EF RNHR", "LEMON", true));   // ATTACK AT DAWN

🌍 6. Cas réel & limites

✓ Usages historiques
  • Diplomatie européenne XVIe–XIXe siècles
  • Confédérés durant la guerre de Sécession
  • Base conceptuelle de chiffrements stream modernes
✗ Cassé par Kasiski (1863)
  • Trouver la longueur de clé via les répétitions (test de Kasiski)
  • Diviser le chiffré en colonnes → chaque colonne = César
  • Analyse fréquentielle sur chaque colonne

💥 Failles & attaques connues

Vulnérabilités spécifiques, attaques connues, cassures historiques.

Test de Kasiski (1863)

Les répétitions du chiffré révèlent la longueur de clé via le PGCD des distances entre répétitions.

Indice de coïncidence (Friedman, 1922)

Mesure statistique qui détermine la longueur de clé même sans répétitions évidentes.

Analyse fréquentielle par colonne

Une fois la longueur de clé connue, chaque colonne est un César indépendant → cassé.

Mot-clé court ou dictionnaire

Une clé < 10 caractères ou un mot de dictionnaire est triviale à attaquer.
