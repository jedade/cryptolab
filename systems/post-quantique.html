📖 1. Pourquoi maintenant ?

En 1994, Peter Shor publie un algorithme qui, sur un ordinateur quantique suffisamment puissant, factorise un entier en temps polynomial. Conséquence directe : RSA, ECC, DH cassés instantanément. Même si ces machines n'existent pas encore, les attaquants peuvent dès aujourd'hui collecter du trafic chiffré pour le déchiffrer plus tard (« harvest now, decrypt later »).

Le NIST a lancé en 2016 un appel à candidats. En août 2024, il a publié les premiers standards : ML-KEM (FIPS 203, ex-Kyber) pour l'échange de clés, ML-DSA (FIPS 204, ex-Dilithium) et SLH-DSA (FIPS 205, ex-SPHINCS+) pour les signatures.

🧮 3. LWE — Learning With Errors

Problème fondateur derrière Kyber et Dilithium. Données :

A ∈ ℤqm×n,   s ∈ ℤqn (secret),   e ∈ ℤqm (petit bruit)
b = A·s + e (mod q)

Étant donné (A, b), retrouver s est facile sans bruit (Gauss) mais conjecturé difficile avec bruit — y compris pour un ordinateur quantique. C'est sur ce problème que repose toute la confiance en Kyber.

✍️ 5. Dilithium — signatures sur réseaux

Dilithium (ML-DSA) est le standard NIST de signature post-quantique construit via la transformation Fiat-Shamir avec abandon sur Module-LWE. Les signatures sont de l'ordre de 2 à 4 Ko (vs ~64 octets en ECDSA), ce qui pose un défi pour les certificats TLS et les blockchains. FALCON est plus compact (~1 Ko) mais plus complexe à implémenter de manière sûre.

ML-KEM-768
Clé publique : 1184 octets · Chiffré : 1088 octets
ML-DSA-65
Clé pub : 1952 · Signature : 3293 octets
SLH-DSA-128f
Très conservateur · Sig : ~17 Ko

💻 6. Code (LWE jouet)

import numpy as np

n, m, q, eb = 4, 6, 97, 3
s = np.random.randint(0, q, n)              # secret
A = np.random.randint(0, q, (m, n))         # matrice publique
e = np.random.randint(-eb, eb+1, m)         # petit bruit
b = (A @ s + e) % q                         # observation publique

# Chiffrer 1 bit msg ∈ {0,1}
def encrypt_bit(A, b, msg, q):
    r = np.random.randint(0, 2, A.shape[0])
    u = (r @ A) % q
    v = (r @ b + msg * (q // 2)) % q
    return u, v

# Déchiffrer
def decrypt_bit(s, u, v, q):
    diff = (v - u @ s) % q
    return 1 if abs(diff - q/2) < q/4 else 0
// LWE jouet
function lweKeygen(n, m, q, eb) {
  const s = Array.from({length:n}, ()=> Math.floor(Math.random()*q));
  const A = Array.from({length:m}, ()=> Array.from({length:n}, ()=> Math.floor(Math.random()*q)));
  const e = Array.from({length:m}, ()=> Math.floor(Math.random()*(2*eb+1)) - eb);
  const b = A.map((row, i) => (row.reduce((acc,v,k)=> acc + v*s[k], 0) + e[i]) % q);
  return { s, A, b: b.map(v => ((v % q) + q) % q) };
}

🌍 7. Adoption

✓ Déjà déployé

  • Signal PQXDH (2024) — hybride X25519 + Kyber
  • Cloudflare TLS hybride post-quantique
  • Chrome ML-KEM dans TLS 1.3
  • OpenSSH ed25519 + Kyber
⚠️ Défis ouverts
  • Tailles de clés/signatures plus grandes
  • Performance dans IoT / mobile contraints
  • Hybride recommandé tant que la confiance s'établit
  • Migration des certificats X.509
